# 界面文案基线

2026-10-27，R2 全量检查中文、英文消息目录及其页面使用位置。产品内容统一使用以下口径，不改返现引擎与银行资格。

| 内容 | 统一表达与修正 |
| --- | --- |
| 奖励金额 | “预计返现（RewardCash）”，单位 RC。部分档位待计算时称“已算出的预计返现”，不暗示银行已发放或最终确定。 |
| 显示精度 | 计算六位 RC；主金额两位、各档最多六位。仅比例封顶截去不足微 RC 的部分，显示舍入不进入累计。人民币合计后换算到分。 |
| 官方规则 | 采用当前已核实规则估算所有交易，不还原历史活动；移除页面旧标记，其行为仍在“计算口径”说明。已知赏世界分配倍数优先，未知默认登记 / 5X。 |
| 消费额度 | 金额上限称“消费额度 / 消费上限”，不是返现上限；赏世界年度延续，PULSE 半年重置。仅合资格导入消费占用，退款不扣回 / 不释放。 |
| 共享关系 | 规则说明使用条件句：只有明确证据才共享；卡片专属提示才陈述“本卡归属未确认”。 |
| 统计范围 | “涉及结单”可在两个半年重复关联；不将来源数理解为互斥分组，不对半份交易进行来源余额核对。 |
| 汇率 | 公开参考汇率按香港自然日复用，来源参考日期可早于获取日期；示例使用虚构值且不请求 / 不写入公开缓存。 |
| 隐私 | 业务数据仅保留在当前页面；PDF 处理完成释放，刷新 / 关闭 / 重新开始清空结果。公开报价是独立缓存，清除结果会保留该缓存。 |
| 文件数量 | 20 份 / 100 MB 是本页累计限制，不能通过继续分批绕开；限额错误改为减少本次选择或重新开始。单份仍为 25 MB / 200 页。 |
| 文件状态 | “查看文件状态”打开弹窗；关闭不取消 / 不删除结果；“取消本批导入”仅在处理中提供并撤销未提交的本批。移除关闭已完成文件状态的独立操作。 |
| 错误与恢复 | 读取 / 模板 / 字段错误统一归“处理失败”，具体原因原位说明。已完成批次的失败文件需重新选择；刷新重试提示清空当前结果。删除“识别接入中”等历史开发措辞。 |
| 独立性 | 产品是独立估算工具；银行实际发放以银行记录为准。HSBC 名称和 Logo 仅识别支持卡片 / 规则来源，不表示官方产品或背书。 |

所有新增和修改文案均有英文对应项，通过类型约束校验键完整性。保留旧阶段验收的历史描述；当前产品和页面以本文件及 R2 验收为准。
