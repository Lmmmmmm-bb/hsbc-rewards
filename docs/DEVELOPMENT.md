## 通用阶段门槛

阶段按实际依赖执行，不将尚未确认的返现策略作为独立 UI、内存会话和 PDF 提取的前置条件。S1.1 已验收提交后可执行 S2 / S3；S1.2 仍需单独验收提交，S5 不得绕过此门槛。每个正在实施的阶段仍必须验收提交后，才开始下一个独立交付阶段。

- `pnpm typecheck`
- `pnpm lint`
- `pnpm test`
- `pnpm build`
- 本阶段新增业务不变量及对应核心函数测试通过。
- 有 UI 的阶段实际浏览器走查，记录功能、宽度和结果，不把类型检查等同于页面验收。
- 有持久化或网络的阶段核对实际数据边界和请求内容。
- README / CHANGELOG / 本页进度更新后提交；记录提交编号，不提前进入下一阶段。
