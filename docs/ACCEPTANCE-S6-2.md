# S6.2 性能、无障碍与首版最终验收

日期：2026-10-27。前置提交：`040cd9e`。本子阶段及按最新范围定义的首版验收通过。

## 本轮用户确认的验收范围

- 用户明确授权使用 Lighthouse 启动独立本地测试浏览器，仅测试本地页面和合成数据。
- 首版按现有 4 份正式结单验收，至少 10 份扩展样本移至后续，不继续作为本版阻塞项。
- 首版浏览器范围为 Chromium；Safari / Firefox 后续补齐。本轮实测 Chrome 156.0.8078.48 和当前内置浏览器，不声称所有浏览器已通过。

## 发现与修复

- 结果状态最初无障碍得分 96。Lighthouse 指出浅红色警示描述、差异徽章和清除按钮的对比度不足。改用同一 shadcn preset 的默认 Alert、主色标题、主色 Badge / Button；没有修改主题或增加业务 CSS。统一为 `ErrorNotice`，文件错误也沿用同一组件。
- 100 页测试最初约 1.05 秒完成，但出现一次约 88ms 主线程长任务。预检与展示重复计算相同快照，且识别后多个同步步骤连续执行。
- 查询结果现在按不可变 Dataset 与汇率值作弱引用缓存，发布时复用已经通过预检的结果；不同汇率仍全量重算。识别和预检之间让出任务，恢复后再次检查取消 / 批次身份。没有跳过校验，也没有提前提交。
- 新增一项核心回归，验证在让出任务期间取消后，即使替代批次已经提交，迟到结果仍不能写回。

## 100 页端到端测量

使用仓库脚本生成的 100 页、2,000 笔合成消费，双币来源结欠均一致；不包含正式结单数据。测量从文件选择 change 事件开始，到本地识别、整批入账、完整 RC 与 CNY 结果进入 DOM 为止。

浏览器 HTTP 缓存关闭，CPU 不节流；页面本身已加载。公开汇率请求用合成 0.85 参考值响应，以排除外部网络波动。实际公开服务获取和故障恢复已在 S5 单独验证。

| 优化后测量 | 完整结果耗时 | 50ms 及以上主线程长任务 |
| --- | --- | --- |
| 1 | 977.8ms | 0 |
| 2 | 924.8ms | 0 |

三次均低于 5 秒；PerformanceObserver 和 Lighthouse timespan 的整段长任务记录均为空。这里表示未观察到达到 50ms 阈值的任务，不表示每个任务耗时为零。结果适用于本轮设备与合成输入，不推广为任意 PDF、设备或网络的保证。
