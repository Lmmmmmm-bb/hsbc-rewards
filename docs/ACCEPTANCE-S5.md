# S5 在线参考汇率验收

日期：2026-10-27。前置提交：`31dd883`。使用 `http://localhost:5173/` 生产构建。本阶段验收通过；S6 综合样本、兼容、性能和完整无障碍门槛仍单列。

## 实现与来源

- 首次真实结单提交后自动请求；空会话和合成示例不发汇率请求。结果内提供刷新，不增加设置或手动汇率覆盖。
- 唯一固定 GET 地址：`https://api.frankfurter.dev/v2/providers/ecb/rate/hkd/cny`。使用 Frankfurter 的 ECB 指定来源，方向固定 HKD→CNY。
- 仅接受正确币种对、正的有限数值、安全整数百万分率和有效且不晚于今天的参考日期。比会话内已知参考日期更早的响应不能覆盖已有值。
- 请求不带业务参数、请求体、Cookie、凭证或 referrer，不跟随重定向；8 秒超时。浏览器缓存关闭，仅保留当前内存会话的成功快照。
- 刷新失败保留旧快照并标记旧参考值；没有成功快照时保持 null。获取满 24 小时或参考日期距今至少 7 天标为旧值，不后台轮询。
- 参考日期与本次获取时间分别展示。成功刷新统一重算全部历史 RC 封顶与 CNY 参考值；原币 / 入账金额、基础 RC 不改变。
- FX 更新不推进数据版本，避免正在处理的 PDF 批次因参考值变化而失效。清空或离开真实会话会取消请求，迟到响应不能恢复旧会话。

接口依据：[Frankfurter JavaScript 文档](https://frankfurter.dev/javascript/)、[指定来源与 API 文档](https://frankfurter.dev/)。已通过实际 HTTP 返回核实 `Access-Control-Allow-Origin: *` 与响应形状；实际适配器也在本机请求成功。API 的提供日期可能落后于获取日期，页面不称其为交易实时汇率。
