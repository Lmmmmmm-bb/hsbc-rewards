# R1.1 当日公开汇率缓存

2026-10-27，前置提交 `af0d466`。本功能独立验收通过。

- 香港自然日内复用成功取得的公开报价；仅公开汇率、参考日期、获取时间和固定来源版本可进入 `pulse.fx.daily.v1`。PDF、密码、卡片、商户、交易和结果不进入缓存。
- 页面刷新、清除后重新导入、另一次页面实例都可复用当天值；跨天自动更新。没有手动刷新汇率入口。
- 首次失败仍待计算；有旧值则明确标旧并暂用。自动重试采用 30 秒、2 分钟、10 分钟、30 分钟退避；离开 / 回到页面及恢复联网会检查当天状态，成功后不再重复请求。
- 过期参考日期仍标旧值，未来时间、损坏缓存、倒退日期和无法安全计算的报价不被直接采用。浏览器禁止存储时仅保留当前页的公开内存报价。
- 沿用导入与 FX 的独立版本边界；清除 / 离开真实会话取消请求，迟到值不能恢复业务会话。

验证：全工作区 167 项核心测试、类型、lint、build 通过；新增持久缓存字段白名单、损坏 / 拒绝存储、香港午夜、同日跨实例复用、跨日获取、失败自动重试等覆盖。浏览器实际首次获取后刷新再导入，显示“今日缓存”，获取时间未变，手动刷新按钮数量为 0，合成奖励仍完整计算。

此阶段只改变汇率策略；规则弹窗、半年展示、紧凑布局及全页拖放在本轮后续子阶段处理。
