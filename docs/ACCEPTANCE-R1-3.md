## 本次九项要求

1. 当日汇率：香港自然日内复用公开报价，跨刷新不重复请求、跨天自动更新、失败自动重试；无手动刷新按钮。业务数据仍不保存。实现与边界见 R1.1。
2. 顶部“返现规则与算法”弹窗：完整展示三档资格 / 费率 / 消费封顶、11 RC 示例、精度、跨期方法、估算边界、官方链接与核实日期。窄屏内容滚动，关闭按钮保持可用。
3. 精度：内部整数 microRC，保留六位；不逐笔舍弃到分或整 RC。仅比例封顶截去不足 0.000001 RC。主金额两位四舍五入，存在更多小数时另显含零头值；各档最多六位，参考 CNY 在合计后换算到分。官方消费零头延续不被误解为工具估算即银行已发放。
4. 信息密度：缩小页面 / 模块间距，移除重复的分隔线及其内边距；保留必要阅读边距。次要假设和计奖原因在原折叠说明里查看。
5. 文件列表：完成后默认收起，错误 / 待解锁时默认展开；紧凑行显示文件名、状态与页 / 交易摘要，展开区域最大 256px，支持内部滚动。保留密码、重试、移除与整批取消。
6. 返现层级：总 RC 为主视觉，CNY 为参考；每张卡主金额用突出颜色与大字，三档贡献、计奖金额和额度分组展示。单卡占整行，避免空出半个页面。
7. 全页 PDF 拖放：页面任意区域接收文件，进入时出现覆盖提示，松开后通过同一批次流程导入。忙碌时说明处理当前批次；普通文本拖动不拦截。覆盖层不阻挡底层拖放事件。
8. 低存在感点阵：使用固定定位的淡色重复小圆点背景，页面滚动时背景保持原位，无新增业务 CSS 文件。
9. 跨期：顶部可选择全部周期或自然半年。全部时按期列出卡片；跨年自动分组。年度截至本期的占用跨半年连续，PULSE 新半年重新计算；来源结欠始终按完整结单核对。

## 实际验证

- 正式结单 4 份：33 页、135 笔交易、128 笔消费，合并为 1 张双币卡；8 项来源结欠一致，无差异提示。只记录匿名状态，不保存真实页面截图。
- 320 / 360 / 768 / 1280 / 1440：正式结果与合成跨期结果均无整页横向溢出。
- 合成跨半年：上半年 HKD90,000、下半年 HKD30,000 的全资格消费，分别 3,760 / 920 RC。上半年年度占用 90%，下半年年度 100%、PULSE 当期 37.5%，未重复获取全年额度。
- 再加入跨年结单：出现 2025-H2、2026-H1、2026-H2 三组；总计 4,680.24 RC。一个来源结单可以关联多个期间；展示分组不增加交易、不制造核对差异。
- 20 份合成文件：完成后明细为 0 行；展开显示 20 行，区域 256px、内容 1108px，内部滚动。相同浏览器刷新并重新导入，只发生 1 次公开汇率请求。
- 浏览器文件拖放协议：在上传容器外的页面位置进入 / 松开，覆盖提示出现、文件成功计入；普通文本拖动不出现覆盖提示。此为浏览器层文件拖放验收，不将此前用户的原生访达拖放记录当作新版全页原生验收。
- 合成混合批次：损坏文件保留错误，已识别文件在密码正确前不入账；错误密码提示、正确解锁后成功文件整批加入。取消待解锁批次后，文件状态和未提交结果均清空。
- 弹窗 Escape 关闭后焦点回到规则入口；手机弹窗可查看全部内容。内容区可聚焦，PageDown 实测从 0 滚动至 722px，关闭按钮保持可用。刷新后卡片和业务结果清空，当日公开汇率仍可复用。合成交互无页面脚本错误。
