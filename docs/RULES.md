# 官方规则与产品估算口径

当前规则版本 `hsbc-pulse-2026-10-27`，核实日期 2026-10-27。参数由系统维护，用户不可修改。银行原始活动日期与产品历史回算口径分别记录。

## 官方来源

- [RewardCash 条款](https://www.hsbc.com.hk/credit-cards/rewards/terms/)：HKD / RMB 子账户每 250 单位消费获得 1 RC；零头延续至后续交易 / 结单。
- [2026 赏世界条款](https://www.hsbc.com.hk/content/dam/hsbc/hk/docs/credit-cards/rewards/2026-red-hot-rewards-of-your-choice-terms-and-conditions.pdf)：最多额外 5X，年度首 HKD100,000 合资格消费，最多额外 2,000 RC；外币签账折为港币，按交易日期。
- [PULSE 专属条款](https://www.hsbc.com.hk/content/dam/hsbc/hk/docs/credit-cards/unionpay-dual-currency/diamond-card-terms-and-conditions.pdf)：当前活动 2026-07-01 至 2026-12-31，首 HKD80,000 合资格消费额外 5X；内地 / 澳门的人民币或澳门币 QR / Mobile Payment；澳门币折为港币。

规则数值对应基础 40 个基点、两档附加最多各 200 个基点。奖励范围还取决于地区、原币种、支付方式和排除交易；仅币种或商户名称不足以证明全部资格。

## 用户确认的产品处理

- 最新年度 / 半年结构回套每个历史周期，显示“按现行规则回算”。
- 只按已导入数据累计，期初封顶占用为零；退款忽略，不扣回、不释放。
- 登记缺失默认 5X 全部分配赏世界；明确未登记时不计算该档，明确分配倍数时采用识别结果。
- 2026-10-27 补充确认：个人登记生效日期也不限制历史回算。即使结单列出登记区间，仍回套估算，并提示“忽略登记期”；这是产品约定，不等同于银行实际发放资格。
- 有明确证据才共享封顶池，收益仍按卡拆分。
- 奖励保留 microRC 精度用于比例估算，不能把 RC 零头逐笔舍去。总额整数部分与零头不等同于银行逐档实际入账记录。

## 赏世界港币封顶换算

优先使用结单明确给出的银行港币等值。HKD 入账本身已是港币金额；其他账户缺少银行港币等值时，使用最新公开参考汇率进行估算并附估算标记。

输入汇率方向固定为 `1 HKD = x CNY`。例如 x=0.9，CNY250 的参考港币等值为 HKD277.78。封顶占用使用此港币等值；附加奖励按原账户合资格金额计算，仅将超过港币剩余额度的比例截断。

因此跨天更新参考汇率可能改变历史年度的赏世界额度消耗、截断位置和附加 RC，随后再统一换算 CNY 参考金额。基础奖励、原币与入账金额不随此参考值改变。

PULSE 人民币签账保留其账户入账口径，澳门币采用港币入账 / 银行等值；不将赏世界的参考换算无差别套到所有档位。

## 缺失换算依据

没有可用汇率时，受影响的档位和后续同池、同周期计算保留为 `null`，不表示零奖励或满额剩余。其他可以确定的档位继续计算，已确定部分单独保留。不同年度 / 额度池不受其污染。

如果此前已经凭可靠金额耗尽该池，后续该档仍可确定为零，不因缺少无关换算而改为待确认。取回汇率后按完整数据重新计算。

## 实现边界

纯计算函数接收汇率快照，不发请求、不缓存、不持久化、不访问 UI 状态。R1.1 起公开报价按香港自然日缓存，跨天更新、失败自动重试；无手动刷新。公开缓存是唯一新增持久数据，不包含业务内容。参考日期距今至少 7 天仍标旧值，见 [R1.1 验收](ACCEPTANCE-R1-1.md)。

## 小数、累计与展示

- 使用整数 microRC，1 RC = 1,000,000 microRC。普通金额按费率直接累计，不逐笔取整 RC 或舍弃到小数两位。例如 HKD0.01 的基础奖励估算是 0.00004 RC，100 笔累计 0.004 RC。
- 比例封顶时奖励按原金额与剩余额度占比分摊，仅截去不足 0.000001 RC 的部分。展示的计奖金额到分，不能拿其显示值反推更高精度的比例奖励。
- 顶部等概览显示两位四舍五入，精确值保留至六位；先按原精度求合计，再格式化。不同半年显示值之和可能与合计显示值相差一分，原始奖励没有丢失。
- 人民币参考价值最后才四舍五入至小数两位，不影响 RC 或原币入账金额。
- 官方一般条款第 9 条、2026 自主奖赏第 11 条、PULSE 专属第 8 条说明消费零头延续。本工具展示累计估算（含零头），不声称是银行已入账或可立即兑换的 RC；未导入的既往零头未知。

## 自然半年展示

年度 / 半年封顶在完整会话里先算，分组读取逐笔结果与当时池状态。跨上 / 下半年不重置赏世界年度使用；跨年才启用新年度额度。每个半年的 PULSE 额度独立，来源结欠始终按完整结单核对。
