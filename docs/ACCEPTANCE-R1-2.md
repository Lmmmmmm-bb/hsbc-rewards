# R1.2 半年查询与计算精度

2026-10-27，前置提交 `9bb8ed4`。本阶段纯计算 / 查询接口独立验收通过，页面在 R1.3 接入。

- 交易按交易日归入自然半年，跨年自动拆分；不以入账日或结单日期替代交易日。
- 全量引擎先计算一次，每笔结果保留当时的精确池状态。半年只聚合已算出的奖励；赏世界年度使用跨上 / 下半年延续，PULSE 按半年重置。
- 所选半年的年度额度显示截至该半年结束的状态，不使用以后半年的最终占用。共享池的其他卡此前占用也保留，未知汇率状态不补成零。
- 同一份跨半年的结单可关联两个分组；来源结欠仍按完整结单核对，不能用半份交易制造核对差异。真实空卡 / 空结单按明确来源日期归组，不猜测无关联卡片。
- 金额按 microRC 整数累计，保留最多六位；展示四舍五入不参与后续计算。没有逐笔舍弃到分或整 RC。仅比例封顶分摊时截掉不足 0.000001 RC 的部分；人民币参考值最后四舍五入到分。
- 核实 RewardCash 一般条款第 9 条、2026 自主奖赏第 11 条及 PULSE 专属第 8 条，消费零头会延续至后续交易 / 结单。累计估算（含零头）不表示银行已入账 / 可兑换数额，未导入的既往消费零头也未知。

验证：新增 9 项核心测试，全工作区 176 项、类型、lint、build 通过。覆盖共享卡跨半年年度累计与 PULSE 重置、跨年、交易日 / 入账日边界、未知汇率、空卡来源、未舍入分组求和、小额消费累加、交易拆分不改变结果及封顶比例的六位精度。

示例：上半年 HKD90,000、下半年 HKD30,000 的合资格消费，赏世界下半年仅余 HKD10,000 计奖，PULSE 下半年仍有新的半年额度；对应半年估算分别为 3,760 / 920 RC，合计 4,680 RC。不能将两半年各自重新当作一整年计算。
