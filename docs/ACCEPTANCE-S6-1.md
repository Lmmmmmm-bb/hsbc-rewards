# S6.1 首版回归与安全边界

日期：2026-10-27。前置提交：`6435756`。本子阶段独立验收通过，S6 整体尚未完成。

## 回归发现与修复

1. 折叠说明可键盘操作，但没有可见焦点。复用当前 shadcn Button 的 focus-visible 色彩、边框与 ring 工具类，并将 ring 置于组件内部；没有新增 CSS 或主题。
2. 单笔最小金额单位安全，不代表奖励单位及多文件合计也安全。新增失败回归先复现单份和合计溢出；现在解析后、整批发布前均使用同一个应用查询预检。单份异常隔离为读取失败，同批正常文件仍提交；合计异常不发布新快照，保留此前结果。
3. 新参考汇率也先完成预检，数值虽合法但会使结果溢出时不采用，保留此前可计算参考值并说明原因。未将该异常误报为网络失败。
4. PDF 读取显式关闭 `useSystemFonts`，与已捆绑标准字体 / CMap / Worker 的边界一致。只提取文本，不运行文档动作或启用 XFA。

预检复用应用查询和领域函数，不在 UI 重写金额或资格。异常说明不展示外部错误原文。

## 验证结果

- 新增 3 项核心回归：单份溢出与其他文件隔离、合计溢出保留此前快照、异常报价保留可计算参考值。全工作区 158 项、typecheck、lint、build、diff 检查通过。
- 实际浏览器混合导入异常金额与正常合成 PDF：前者失败，后者加入 1 份 / 2 笔交易，页面可继续操作。
- 关闭系统字体回退后，四份正式结单仍得到 135 笔交易 / 128 笔消费，8 项来源结欠全部一致。
- 手机逐档模块兄弟元素的边界未发生重叠；此前 S4 / S5 的五种实际屏宽记录继续有效，布局未变更。
- Enter 操作后，折叠按钮的 `:focus-visible` 为 true，实际显示 2px inset ring 和边框；已经视觉检查。跳至主内容正确聚焦 main。
- 隐私弹窗 Enter 打开、Escape 关闭；清除确认连续 5 次 Tab 焦点保留在弹窗内，Escape 退出后正式卡片与 8 项核对结果保留。
- PDF 文档 / Worker 的取消、成功、迟到及重复释放边界沿用现有核心测试；源代码未增加业务持久化、遥测或非白名单请求。
