# S4 返现解释与质量提示验收

日期：2026-10-27。前置提交：`0c5b7c8`。在 `http://localhost:5173/` 验证生产构建。本阶段已通过；在线参考汇率与首版综合验收分别留在 S5 / S6。

## 交付内容

- 每档汇总封顶后计奖金额、已确定 RC 与原因笔数。待计算档保留其中已知奖励及各币种的未知状态；总览、卡片和明细使用同一引擎输出。
- 计奖 / 排除原因按卡折叠展示：三档共同排除只解释一次，地区、原币、支付、封顶和汇率原因分别列入对应档。
- 核对按来源结单子账户统计一致、差异和无法核对项；全局统计不把共享卡片的来源核对重复相加。
- 疑似重复、凭证冲突、余额缺失及资格依据不足有只读提醒。没有交易修正或规则编辑入口。
- 额度视图补全已观察历史周期的零占用池，未使用额度显示完整剩余；真实缺少汇率的池仍显示待计算，不补成零。只有明确共享证据才共用额度。
- 单张卡占满结果宽度，桌面两档额度并排；多卡并列，手机逐卡顺序展示。使用现有 shadcn 组件与 Tailwind 布局。
