# Pulse Rewards 产品基线

当前产品是面向个人的单页返现工具：上传 HSBC Pulse 银联双币卡英文 PDF，在同一页查看三档返现估算。页面只有导入与返现这一条主流程，不提供账单工作台、设置页或多页导航。

本版以 2026-10-27 用户最新确认的范围为准，替代早期四页线稿。UI 使用 shadcn `b4hZZS5Uu` preset；不维护自定义业务样式表。

## 核心流程

1. 始终显示同一个返现工作区：上传、总览、逐卡返现与计算规则，不区分首页和上传后页面。未读取时用占位值，不用零金额伪装结果；也可查看明确标注的合成示例。
2. 本地读取、多文件状态和密码解锁在原页完成；错误与取消不影响此前成功的会话数据。
3. 批次完成后统一纳入成功解析的消费，在上传区旁显示 RC 和 CNY 参考返现。
4. 每张卡直接显示尾号 / 主副卡、入账币种、结单覆盖时间、交易 / 消费笔数、分币种消费金额、三档 RC 与封顶后的计奖金额，以及年度 / 半年额度使用和剩余；不把主要返现藏在折叠面板里。
5. 三档计算规则、费率、资格和封顶常驻展示。版本、完整估算口径和官方来源折叠呈现；保留必要的质量提醒，精简宣传内容。
6. 可以继续加入文件或重新开始。刷新 / 关闭页面后，文件与结果均消失。

处理完成即释放原 PDF 及 PDF Worker，只在内存中保留本次解析数据和估算结果。不上传、不落盘，不保留原件预览、历史、备份或本地加密档。

## 已确认的计算口径

- 使用最新已核实的官方费率、资格和封顶结构。版本、来源及核实日期可查，不允许修改规则或逐笔交易。
- 最新规则回套各历史年度 / 半年，各周期分别封顶，标明“按现行规则回算”；不声称重现历史实发。
- 只按本次已导入消费占用额度，此前占用视为零。
- 退款、还款、费用等不赚取返现；退款不扣回返现、不释放封顶额度。内部账务核对仍包含其方向和金额。
- 商户地区、支付方式、分类完全由系统判断；缺少证据时保守判定并保留原因，不提供人工覆盖入口。
- 无法确认赏世界登记时，默认已登记且 5X 全部分配赏世界，并提示假设。
- 收益按卡拆分；只有明确归属证据才共享封顶池，关系不明时分开计算并提示。
- 文件按 SHA-256 去重；跨文件交易仅凭银行唯一证据和一致关键字段合并，疑似重复保留并提示。
- 金额核对不一致仍计入返现，在同页作质量提醒，不增加账单核对页面。
- 最新参考汇率统一折算历史 CNY 参考金额。赏世界封顶优先用银行港币等值，缺失时用最新参考汇率估算，并提示刷新可能改变附加 RC。
- 汇率缺失显示待换算 / 待计算，不能当作零奖励。原币与入账金额不被参考汇率改写。
- 批次结束后统一提交成功文件；取消撤销整个本批，保留此前已导入数据。过期异步结果不能写回新批次。

## 当前首版范围

| 能力 | 必须覆盖的行为 |
| --- | --- |
| 文件输入 | 多选、拖放、类型 / 头部校验、单份 25 MB / 200 页、会话 20 份 / 100 MB、指纹去重 |
| 本地处理 | Worker、文本坐标、英文结单模板、卡片 / 子账户、日期、原币 / 入账金额、警告与置信度 |
| 解锁与批次 | 密码仅本次调用使用、错误原位反馈、5 次错误冻结 60 秒、重试、移除、取消、统一提交 |
| 返现结果 | 总 RC / CNY 参考值、按卡三档、资格理由、周期封顶、额度剩余、共享证据、估算假设 |
| 参考汇率 | 自动获取公开参考值、结果内刷新及来源 / 过期状态、失败时待计算；不设置独立设置页 |
| 说明与控制 | 同页规则说明、必要质量警告、隐私声明、重新开始；不暴露交易编辑 |
| 内存生命周期 | 成功提取释放 PDF / Worker；本次解析数据与结果仅保留至清除 / 刷新 / 关闭 |

不再实施原四页方案中的账单列表、全局交易搜索、筛选预设、账单 CSV、设置页和持久化功能。原加密档、备份、跨会话历史不纳入当前开发目标；若将来重新提出，需单独确认范围。

后续改进只围绕本地导入质量和返现准确性展开。OCR、更多汇率源和官方促销仍是候选项，未排期，不能自动扩展为保存或账户管理功能。

## 验收与限制

- 公开汇率请求不携带卡号、商户、金额、文件。静态字体、PDF Worker 和支持资源随应用提供。
- 不使用 localStorage、IndexedDB、Cookie 或服务端保存业务数据。
- 320 / 360 / 768 / 1280 / 1440 宽度检查；键盘、文件解锁、取消、清除、刷新及错误状态实际验收。
- 性能 / Lighthouse 原目标保留待实测：性能 90、无障碍 95；约定设备上 100 页端到端小于 5 秒、主线程长任务小于 50 毫秒。
- 最终脱敏真实验收集目标至少 10 份，解析成功率至少 95%、金额核对一致率至少 99%。现有授权真实样本为 4 份带加密标记但可直接读取的 PDF，缺少的 6 份不能以合成或复制文件充数。

当前已完成领域计算与本地文本提取。四份正式结单已成功提取 33 页文本，真实结单交易模板仍待校准；演示返现不代表真实导入已验收。状态和证据见 DEVELOPMENT.md。
