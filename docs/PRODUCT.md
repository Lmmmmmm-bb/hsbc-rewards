# Pulse Rewards 产品基线

浏览器本地分析 HSBC Pulse 银联双币卡英文 PDF 结单，提供交易明细、HKD / CNY 子账户结欠核对、三档返现估算和导出。首版以已评审线稿的导入、对账、返现、设置四页构成完整闭环。

## 已确认的计算和交互口径

1. 使用最新已核实官方费率、资格和封顶结构，显示规则来源、版本及核实日期；规则不允许用户修改。
2. 最新规则回套各历史年度 / 半年，各周期独立占用额度。显示“按现行规则回算”，不声称重现历史实发。
3. 只按已导入交易计算；此前额度占用视为零，不补录期初额度。
4. 退款保留在明细和结欠核对中，但完全不参与返现：不赚取、不扣回、不释放封顶。
5. 商户地区、支付方式、分类全部自动识别，不提供逐笔覆盖或强制通过。
6. 地区和支付方式证据不足时保守判定，并保留未知原因与低置信度警告。
7. 无法确认赏世界登记时，假设已登记且 5X 全部分配赏世界，并公开提示这一估算假设。
8. 收益按卡拆分；只有明确归属证据才共享封顶池，关系不明时分开计算并提示。
9. 同一 PDF 按 SHA-256 去重；跨文件交易仅凭唯一证据合并，疑似重复保留并提示。
10. 结欠不一致仍展示明细、计入估算，并醒目显示差额。
11. 最新参考汇率统一换算所有历史 CNY 参考值；奖励原值、原币和入账金额分别保留。缺失汇率显示待换算，不显示零。
12. 一次选择构成一个批次。批次结束后统一提交成功文件；取消撤销本批全部结果，保留此前数据。
13. 首版业务数据仅在内存；密码解析结束即释放；原 PDF 不提交到仓库、不上传。
14. 后续加密档只存解析数据。重新选取指纹相同的 PDF 恢复预览，不重复导入交易。

## 首版功能清单

| 编号 | 功能 | 必须覆盖的行为 |
| --- | --- | --- |
| IMP | 导入 | 多文件、拖放、PDF 类型、25 MB / 200 页单份限制、20 份 / 100 MB 会话限制、指纹去重 |
| QUE | 批次 | queued / parsing / locked / ready / review / error、进度、重试、单份移除、整批取消、成功文件统一提交 |
| PWD | 解锁 | 内存密码、错误原位反馈、5 次错误冻结 60 秒、取消不影响其他文件 |
| PAR | 解析 | 原文、页码、坐标、模板版本、日期推断、卡片与子账户、原币 / 入账金额、置信度与警告 |
| REC | 核对 | 按子账户借贷项核对、matched / mismatch / unverified、可疑来源、报告到原页定位 |
| LED | 明细 | 日期 / 币种 / 方向 / 分类 / 卡 / 来源筛选、日期与金额排序、分页、无数据 / 无结果、两组筛选预设 |
| SEA | 搜索 | Cmd/Ctrl+K、商户模糊搜索、精确金额、分类、卡片、直达交易详情 |
| REW | 返现 | 三档叠加、只读规则、逐笔理由、额度截断、独立年度 / 半年、卡片与额度池分离 |
| FX | 汇率 | 公开参考源、刷新、最近缓存及过期标记、全部失败时待换算 |
| PDF | 溯源 | 本地 PDF 预览、页码和行高亮、关闭 / 取消 / 清除时资源释放 |
| EXP | CSV | 当前筛选的全部结果、低置信度排除、Excel 中文、公式防护、时间戳文件名 |
| SET | 设置 | 中英、浅色 / 深色 / 系统、标准 / 紧凑、本地计数关闭 / 清零、清除会话、隐私与独立声明 |

筛选只选择已计算的交易奖励，不重算或重新分配封顶。支出按账户币种分别汇总，不把不同币种直接相加。

## 后续完整路线

- 本地加密保存：显式开启、密码规则和不可找回提示、迁入会话或新档、解锁、单独擦库及 DELETE 确认。
- 备份迁移：带版本 JSON、加密 .pulsevault、合并 / 替换、恢复校验、原 PDF 重新关联。
- 历史分析：加密档内跨会话月 / 季 / 半年 / 年趋势，卡片和分类拆分，聚合数据 CSV。
- 多源公开汇率回退，统一最新参考值，来源与缓存过期信息可查。
- 多级解析兜底及显式开启的本地 OCR；OCR 进入返现的采信机制在实施前对齐，不能引入逐笔编辑。
- 经核实的官方促销规则；活动登记缺失与真实活动日期如何映射到历史回算需实施前对齐，不提供自定义活动参数。
- PWA 安装、资源缓存及完整离线能力；离线时汇率状态明确。
- 脱敏诊断包及真实样本库扩充；用户主动导出，不自动发送。

## 全阶段约束与最终验收

- 只有公开汇率服务可以接收业务外请求，且请求不能包含卡号、商户、金额或文件。静态依赖与字体随应用提供。
- 默认不持久化结单、交易、卡片、密码、原件。后续只有用户开启的加密档可持久保存业务数据。
- 所有产品文案使用中英文 key，金额和日期使用 Intl，键盘与屏幕阅读器可访问。
- 360 / 768 / 1280 / 1440 四断点无页面溢出；Lighthouse 性能目标 90、无障碍目标 95。
- 在约定设备上 100 页 PDF 端到端目标小于 5 秒，主线程长任务目标小于 50 毫秒。
- 最终真实脱敏验收集目标至少 10 份，解析成功率至少 95%、结欠核对一致率至少 99%。目前已获授权的真实样本为 Downloads 中 4 份，不能将合成或变体文件计为额外真实样本。

上述是验收目标，不代表当前实现已达到。当前进度和证据见 DEVELOPMENT.md。
