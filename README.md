# Reward+

你的 HSBC PULSE 结单返现助手。

导入 HSBC PULSE 银联双币钻石卡的英文 PDF 结单，在同一页查看预计返现（RewardCash）、逐卡奖励明细和剩余消费额度。PDF 与密码只在本机处理，结果仅保留在当前页面。

## 开始使用

1. 点击「查看示例」，先用虚构数据熟悉页面。
2. 点击「选择 PDF 文件」，或把多份 PDF 拖到页面。导入自己的结单会清除示例。
3. 在「文件状态」中查看进度；加密结单可在此输入密码解锁。关闭弹窗后仍会继续处理。
4. 本批结束后，成功文件统一计入结果。查看总览、逐卡明细，或按自然半年切换。
5. 需要补充结单时，再次选择文件，或在文件状态中点击「补充文件」。

处理中点击「取消本批导入」会撤销本批，保留此前结果。点击「重新开始」并确认，可清空当前结果。

## 可以查看什么

- **预计返现（RC）**：基础奖励、赏世界及 PULSE 专属奖励的贡献，以及人民币参考价值。
- **逐卡明细**：消费金额、计奖和排除原因、已用及剩余消费额度。
- **自然半年结果**：按每年 1–6 月、7–12 月查看，跨年自动拆分。
- **数据提示**：结欠核对差异、疑似重复交易，以及缺少计算依据的部分。

## 怎样理解结果

**RC 是预计 RewardCash，人民币金额是参考价值，实际返现以银行记录为准。** 人民币价值按 `1 RC ≈ 1 HKD`，再用港币兑人民币参考汇率折算，不代表已发放或可立即兑换的金额。

页面中的「返现规则与算法」列出了奖励条件、费率、消费上限、计算示例、规则核实日期及官方来源。使用时请留意：

- **历史结单按当前已核实规则估算**，不还原历史活动，也不会自动追踪银行条款变化。
- **只计算已导入消费**，此前占用额度视为零。赏世界额度按自然年累计，PULSE 额度每半年重置；只导入部分结单时，剩余额度可能高于实际。
- **登记信息缺失时存在假设**：赏世界按已登记且全额 5X 估算，有明确登记状态或分配倍数时采用识别结果。历史回算不限制个人登记生效期，实际资格仍以银行记录为准。
- **退款不赚取奖励，也不扣回此前估算或恢复额度**。还款、费用、现金预借等排除项目不计奖。
- **每张卡分别展示收益**，仅有明确归属证据时共享消费额度；关系不明时分开估算并提示。
- **缺少依据的部分保持待计算**，不当作零奖励。地区、币种和支付方式由结单信息判断，目前不能手动修改交易或规则。
- **计算保留六位 RC，主金额显示两位**。各卡或各半年的显示值相加，可能与总览相差 0.01；显示舍入不影响实际累计。

赏世界封顶优先采用银行给出的港币等值，缺失时用参考汇率估算。汇率更新可能改变人民币参考价值，以及部分受封顶影响的附加 RC。

## 隐私与联网

PDF、密码、结单数据和返现结果均不上传。密码仅用于本机解锁；结单数据和结果只保留在当前页面，刷新、关闭或「重新开始」后清空。没有账户注册、历史记录、保存或导出功能，需要再次查看时请重新选择结单。

真实结单导入后，工具会向 [Frankfurter](https://frankfurter.dev/) 获取 ECB 的港币兑人民币公开参考汇率。请求不携带结单、密码、卡号、商户或交易金额，也不使用埋点统计。仅公开汇率会在本机缓存，自获取起复用 6 小时，到期自动更新，失败后自动重试；清空结果时保留此缓存。示例使用虚构汇率。

## 常见问题

| 情况 | 处理方式 |
| --- | --- |
| 文件需要密码 | 在「文件状态」中解锁；连续输错 5 次后等待 60 秒 |
| 未识别结单或没有可读取文本 | 确认卡种、英文文本格式及文件完整性；扫描件暂不支持 |
| 部分文件失败 | 查看原因并重新选择失败文件；成功文件仍会在本批结束后计入 |
| 相同文件已跳过 | 该 PDF 已在本批或当前结果中，无需重复加入 |
| 疑似重复或结欠核对有差异 | 对照原结单检查；提示不会自动删除交易，疑似重复仍可能计入估算 |
| 参考汇率暂不可用 | 等待自动重试；可确定的奖励继续显示，其余保持待计算 |
| 弹窗内容无法加载 | 点击「重新加载内容」，或关闭后再打开；无需刷新页面 |
| 达到累计文件或大小限制 | 减少本次选择，或查看结果后「重新开始」 |
