# Reward+

导入 HSBC PULSE 银联双币钻石卡的英文 PDF 账单，查看预计返现（RewardCash）、逐卡明细和剩余消费额度。PDF 与密码仅在本机处理，结果只保留在当前页面。

## 开始使用

1. 空白页面点击「查看示例」，用两张卡、六份虚构账单和三个半年周期熟悉页面，体验多币种、消费封顶及退款等场景。有文件记录或结果时隐藏此按钮，重新开始后可再次查看。
2. 点击「选择 PDF 文件」或拖入多份 PDF，导入后清除示例，改用自己的账单。
3. 在「文件状态」中查看进度、解锁加密账单。关闭弹窗后继续处理。
4. 本批结束后，成功文件统一计入结果；可查看总览、逐卡明细，或按自然半年切换。
5. 本批结束后可再次选择文件，或在文件状态中点击「补充文件」。

「取消本批导入」会撤销本批，保留此前结果。「重新开始」并确认后清空当前账单和结果。

顶部「English / 简体中文」可随时切换语言，不影响结果或正在处理的文件。页面优先使用已保存的手动选择，否则采用浏览器偏好中首个支持的语言，无匹配时使用简体中文。界面语言不改变仅支持英文账单的范围。

## 可以查看什么

- **预计返现（RC）**：基础奖励、赏世界、PULSE 专属奖励及人民币参考价值。
- **逐卡明细**：消费金额、计奖和排除原因、已用及剩余消费额度。
- **半年结果**：按每年 1–6 月、7–12 月查看，跨年分别汇总。
- **数据提示**：账单余额核对差异、疑似重复交易，以及缺少计算依据的部分。

## 与浏览器助手配合

支持 WebMCP 和文件传入的浏览器助手，可使用本页已有的分析流程。打开底部「助手协作」，允许读取结果后，助手可传入你指定的 PDF，查询导入进度、预计返现、逐卡与半年结果及质量提示。需要密码时，在页面中解锁。

共享包括当前及本页后续补充导入的结果，交易描述默认不返回。可随时「停止共享」；刷新、关闭或「重新开始」后失效。示例使用虚构数据，可直接读取。浏览器或助手不支持时，仍可正常使用人工导入。

助手可能将读取的结果发送到其模型服务。共享控制只限制本站工具输出，不能认证助手身份，也不能阻止已具有页面访问权限的扩展读取页面；停止共享不能收回此前已读取的数据。

供助手阅读的[站点简介](https://rewards.lmmmmmm.dev/llms.txt)和[WebMCP 使用说明](https://rewards.lmmmmmm.dev/webmcp.txt)公开提供，不含当前页面的账单或结果。

## 怎样理解结果

**RC 为预计 RewardCash，实际返现以银行记录为准。** 人民币参考价值按 `1 RC ≈ 1 HKD`，再以参考汇率折算，不代表已发放或可立即兑换的金额。

「返现规则与说明」提供奖励条件、费率、消费上限、示例、核实日期及官方来源。主要估算口径：

- **历史账单按当前已核实规则估算**，不还原历史活动，也不会自动追踪银行条款变化。
- **仅已导入消费占用额度**，此前占用视为零。赏世界按自然年累计，PULSE 每半年重置；账单不全时，剩余额度可能高于实际。
- **登记或倍数缺失时**，按已登记、额外 5X 全部分配给赏世界估算；有明确记载时按账单计算。历史估算不受个人登记生效日期限制，实际资格以银行记录为准。
- **退款不赚取奖励，也不扣回此前估算或恢复额度**。还款、费用、预借现金等排除项目不计奖。
- **逐卡展示收益**，仅在共享关系明确时合并消费额度；否则分别估算并提示。
- **缺少计算依据的部分保持待计算**，不当作零奖励。地区、币种和支付方式按账单判断，交易和规则不可手动修改。
- **RC 计算保留六位小数，总览和卡片合计显示两位**。显示舍入不影响计算，各卡或周期显示值相加可能与总览有差异。

赏世界消费额度优先使用银行港币等值，缺失时按参考汇率估算。汇率更新可能改变人民币参考价值及受消费上限影响的额外奖励。

## 隐私与联网

Reward+ 的本机分析流程不上传 PDF、密码、账单数据或返现结果。密码仅用于本机解锁；账单数据和返现结果仅存于当前页面，刷新、关闭或「重新开始」后清空。主动开启助手协作时，结果可交给浏览器助手，其模型服务的数据处理方式由助手提供方决定。无账户、历史记录、保存或导出功能，再次查看须重新导入。

导入账单后，工具向 [Frankfurter](https://frankfurter.dev/) 获取 ECB 港币兑人民币公开参考汇率，请求不含账单、密码、卡号、商户或金额，无埋点统计。汇率在本机缓存，获取后复用 6 小时，到期自动更新，失败后自动重试。示例使用虚构汇率，不请求或缓存公开汇率。

手动选择的语言单独保存在本机，刷新或再次访问时沿用；浏览器禁止存储时，仅本页有效。清空结果保留公开汇率缓存和语言偏好。

## 常见问题

| 情况 | 处理方式 |
| --- | --- |
| 文件需要密码 | 在「文件状态」中解锁；连续输错 5 次后等待 60 秒 |
| 未识别账单或无可读取文本 | 检查卡种、英文文本格式及文件完整性；不支持扫描件 |
| 部分文件失败 | 查看原因并重新选择失败文件；成功文件仍会在本批结束后计入 |
| 相同文件已跳过 | PDF 已在本批或当前结果中，无需重复加入 |
| 疑似重复或账单余额核对有差异 | 对照原账单检查；提示不会自动删除交易，疑似重复仍可能计入估算 |
| 参考汇率暂不可用 | 等待自动重试；已确定的奖励继续显示，其余待计算 |
| 弹窗内容无法加载 | 点击「重新加载内容」，或关闭后再打开；无需刷新页面 |
| 达到累计文件或大小限制 | 减少本次选择，或查看结果后「重新开始」 |
