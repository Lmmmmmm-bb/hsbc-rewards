# Reward+

导入 HSBC PULSE 银联双币钻石卡的英文 PDF 账单，在本机查看预计返现（RewardCash）、逐笔计算明细和剩余消费额度。

**[打开 Reward+](https://rewards.lmmmmmm.dev/)**

账单和结果仅保留在当前页面，刷新、关闭或「重新开始」后清空。还没有准备好账单时，可在空白页面点击「查看示例」，体验两张卡、六份虚构账单的分析结果。

## 开始使用

1. **选择账单**：点击「选择 PDF 文件」，或将一份或多份 PDF 拖入页面。
2. **等待处理**：在「文件状态」中查看进度；加密账单需在页面中输入密码解锁。关闭弹窗后，导入仍会继续。
3. **查看结果**：本批处理结束后，成功文件统一计入估算。可查看全部周期，或按每年 1–6 月、7–12 月切换结果。
4. **补充账单**：等本批结束后，再次选择文件，或在文件状态中点击「补充文件」。处理期间，当前结果只包含此前已计入的账单。

「取消本批导入」会撤销尚未计入的本批文件，保留此前结果。「重新开始」需确认，会清空账单、文件状态和返现结果，之后可重新导入或查看示例。导入自己的 PDF 后，示例会被替换。

顶部「English / 简体中文」可随时切换语言，不影响结果或正在处理的文件。页面优先沿用手动选择，否则按浏览器语言偏好显示，无匹配或初始化失败时使用简体中文。界面语言不改变仅支持英文账单的范围。

## 支持范围

| 项目 | 范围 |
| --- | --- |
| 卡种与格式 | HSBC PULSE 银联双币钻石卡英文文本 PDF，支持本机解锁加密账单 |
| 单份限制 | 不超过 25 MB、200 页 |
| 当前页面累计限制 | 最多 20 份、合计 100 MB，含分批补充 |
| 暂不支持 | 扫描件、图片、其他语言或卡种；不支持扫描文字识别（OCR） |

建议使用 Chromium 浏览器；Safari 和 Firefox 的兼容性尚待验证。交易和计算规则不可手动修改。

## 查看与理解结果

**RC 为预计 RewardCash，实际返现以银行记录为准。** 三项奖励分别判断资格，符合条件时可叠加。人民币参考价值按 `1 RC ≈ 1 HKD`，再以参考汇率折算，不代表已发放或可立即兑换的金额。

### 在哪里查看明细

| 入口 | 可以查看的内容 |
| --- | --- |
| 返现总览 | 基础奖励、赏世界、PULSE 专属奖励的合计，以及估算依据和异常提示 |
| 逐卡预计返现 | 每张卡的三项奖励；每个半年对应的消费额度用量、累计截至点和观测交易范围 |
| 「查看交易明细」 | 按卡片、奖励项和计算状态筛选交易，每页 20 笔；进入单笔详情查看金额、计奖或排除原因和来源账单 |
| 「查看相关记录」、卡片的「查看明细」或具体计奖原因 | 定位与卡片、原因或质量提示相关的交易 |

单笔详情中的「已提取的来源文本」按页展示该笔交易的来源文字；跨账单合并的交易保留每份来源。返回列表会保留筛选、分页和位置。卡片上的额度与质量标签仅展示状态。

### 估算口径

- **规则与历史周期**：历史账单采用当前已核实规则，不还原历史活动，也不会自动追踪银行条款变化。半年结果按交易日期汇总，同一账单可跨多个周期。
- **消费额度**：只扣除已导入的消费，此前占用视为零。赏世界按自然年累计，7 月不重置；PULSE 每半年重置。账单不全时，剩余额度可能高于实际，观测日期也不代表期间账单完整。
- **登记与倍数**：赏世界登记或倍数信息缺失时，按已登记、额外 5X 全部分配给赏世界估算；有明确记载时按账单计算。历史估算不受个人登记生效日期限制，实际资格以银行记录为准。
- **多卡与共享额度**：收益逐卡展示，仅在共享关系明确时合并消费额度，否则分别估算并提示。同一共享额度池在同一半年内只展示一次，用量不可跨卡重复相加。
- **退款与排除项目**：退款不赚取奖励，也不扣回此前估算或恢复消费额度。还款、费用、预借现金、储值充值等排除项目不计奖，但仍参与账务核对。
- **待计算与资格判断**：缺少计算依据的部分保持待计算，不当作零奖励；已确定的奖励继续展示。地区、币种和支付方式缺少证据时保守判断，参考汇率不能作为资格证据。
- **参考汇率**：赏世界消费额度优先使用银行港币等值，缺失时按参考汇率估算。汇率更新可能改变人民币参考价值及受消费上限影响的额外奖励。
- **精度与舍入**：RC 计算保留六位小数，页面金额显示两位，计算明细最多显示六位。非零但两位舍入为零的奖励显示 `<0.01 RC`。显示舍入不影响计算，各卡或周期显示值相加可能与总览有差异；银行实际返现还可能受未导入的历史消费零头影响。

奖励条件、费率、消费上限、计算示例、核实日期及官方来源，可在页面的「返现规则与说明」中查看。

### 去重与质量提示

相同 PDF 会自动跳过。跨文件交易只有银行唯一凭证与关键字段一致时才合并；疑似重复会保留并提示，仍可能计入估算。

质量提示随所选半年关联的来源账单变化，账单余额核对始终覆盖完整来源账单。同一账单跨半年时可在两个半年出现，在「全部周期」中只计一次。余额质量提示可定位对应来源子账户在当前范围内的交易；核对差异只作提示，不会自动删除交易。

## 隐私与联网

账单导入与返现计算在本机完成，不向 Reward+ 上传 PDF、密码、账单数据或结果。工具无账户、历史记录、保存或导出功能，再次查看结果须重新导入。

| 数据 | 处理与保留方式 |
| --- | --- |
| PDF 与密码 | 仅用于本次本机处理，不保存原件或密码；文本提取完成后释放 PDF，密码仅用于单次解锁 |
| 账单数据与返现结果 | 仅保留在当前页面内存，刷新、关闭或「重新开始」后清空 |
| 公开参考汇率 | 仅缓存公开报价、参考日期和获取时间；获取后复用 6 小时，到期自动更新，失败后自动重试 |
| 界面语言 | 手动选择后单独保存在本机；浏览器禁止存储时，仅本页有效 |

导入账单后，工具向 [Frankfurter](https://frankfurter.dev/) 获取 ECB 港币兑人民币公开参考汇率，请求不含账单、密码、卡号、商户或金额。工具无埋点统计。示例使用虚构汇率，不请求或缓存公开汇率。「重新开始」保留公开汇率缓存和语言偏好。

主动允许 AI 工具读取结果后的共享范围与处理方式见下节。

## 与 AI 工具配合

支持 WebMCP 的浏览器 AI 工具可读取本页分析结果；同时支持浏览器文件传入时，还可传入你指定的 PDF。密码仍在页面中输入。

1. 打开页面底部的「AI 接入」。
2. 点击「允许读取结果」，允许 AI 工具查询导入进度、预计返现、消费额度、逐笔金额与原因及质量提示。交易描述默认不返回，可按需读取。
3. 需要结束共享时，点击「停止共享」。

共享覆盖当前及本页后续补充导入的结果，刷新、关闭或「重新开始」后失效。示例使用虚构数据，可直接读取；切换到真实账单后需开启共享。

「允许读取结果」不可用时，可悬停、键盘聚焦或轻点按钮区域查看原因。未检测到 WebMCP 时，可尝试在 Chrome 的 `chrome://flags` 中搜索并启用 WebMCP，重启后重试；启用要求以 [Chrome 官方说明](https://developer.chrome.com/docs/ai/webmcp#local-webmcp)为准。准备中可稍候，接入失败可点击「重试接入」。浏览器或 AI 工具不支持时，仍可正常使用页面导入。

AI 工具可能将读取的结果发送到其模型服务，数据处理方式由工具提供方决定。共享控制只限制本站工具输出，不能认证 AI 工具身份，也不能阻止已具有页面访问权限的扩展读取页面；停止共享不能收回此前已读取的数据。

## 常见问题

| 情况 | 处理方式 |
| --- | --- |
| 文件需要密码 | 在「文件状态」中解锁，或移除该文件；连续输错 5 次后等待 60 秒。仍有待解锁文件时，本批不会计入结果 |
| 未识别账单或无可读取文本 | 检查卡种、英文文本格式及文件完整性；不支持扫描件 |
| 部分文件失败 | 查看原因，等本批结束后重新选择失败文件；成功文件仍会在本批结束后统一计入 |
| 相同文件已跳过 | PDF 已在本批或当前结果中，无需重复加入 |
| 疑似重复或账单余额核对有差异 | 打开相关交易明细，对照原账单检查；提示不会自动删除交易 |
| 参考汇率暂不可用 | 等待自动重试；已确定的奖励继续显示，其余待计算 |
| 弹窗内容无法加载 | 点击「重新加载内容」，或关闭后再打开；无需刷新页面 |
| 达到累计文件或大小限制 | 减少本次选择，或查看结果后「重新开始」；重新开始会清空当前结果 |
