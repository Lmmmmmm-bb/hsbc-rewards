# Rewards

你的 HSBC PULSE 结单返现助手。

选择 HSBC PULSE 银联双币钻石卡的英文 PDF 结单，即可在同一页查看预计 RewardCash、每张卡的奖励明细和剩余消费额度。PDF 与密码只在本机处理，返现结果仅在当前页面保留。

## 可以查看什么

| 内容 | 帮你了解 |
| --- | --- |
| 预计返现（RC） | 基础奖励、赏世界与 PULSE 专属奖励分别贡献多少 |
| 人民币参考价值 | 按公开参考汇率折算后的大致价值 |
| 每张卡的明细 | 消费金额、三档奖励、计奖与排除原因 |
| 消费额度 | 已导入消费占用了多少额度，还剩多少 |
| 自然半年结果 | 按每年 1–6 月、7–12 月查看返现，跨年自动拆分 |
| 数据提示 | 结欠核对差异、疑似重复，以及尚缺计算依据的部分 |

## 开始使用

1. **先试试看**：点击“查看示例”，用虚构数据熟悉返现总览。选择自己的 PDF 后，示例会被清除。
2. **加入结单**：点击“选择 PDF 文件”，或把多份 PDF 拖到页面任意位置。
3. **查看处理状态**：点击“查看文件状态”了解进度。遇到加密结单，在弹窗中输入该文件的密码进行本机解锁；关闭弹窗后仍会继续处理。
4. **查看返现**：本批处理结束后，成功文件统一计入结果。可以查看总览、逐卡明细，或切换自然半年。
5. **继续补充**：本批结束后，可再次选择文件，或在文件状态弹窗内点击“补充文件”。已有返现保留，列表显示新一批的处理状态。

处理中点击“取消本批导入”会撤销本批，保留此前已计入的结果。需要清空时，点击“重新开始”并确认。

## 支持的结单

- **卡片与格式**：HSBC PULSE 银联双币钻石卡的英文文本 PDF 结单，支持本机密码解锁。
- **单份限制**：不超过 25 MB、200 页。
- **当前页面累计限制**：最多 20 份、合计 100 MB，分批补充也计入累计数量。
- **暂不支持**：扫描件、图片、其他语言或其他卡种的结单；尚未提供扫描文字识别（OCR）。

当前已通过 Chromium 浏览器和 4 份真实结单的验证。Safari、Firefox 及更多结单样本仍待验证。

## 怎样理解返现结果

**RC 是预计 RewardCash，人民币金额是参考价值。** 工具按 `1 RC ≈ 1 HKD` 的参考价值，再使用港币兑人民币参考汇率折算。它们都不代表银行已发放或可立即兑换的金额。

页面顶部的“返现规则与算法”列出三档奖励的条件、费率、消费上限、计算示例和官方来源。理解结果时，尤其需要留意以下口径：

- **历史结单统一采用当前已核实规则估算**，不还原各历史活动；规则版本和核实日期可在页面查看，工具不会自动追踪银行条款变化。
- **只计算已导入的消费**，此前已占用额度视为零。赏世界额度按自然年累计，7 月不重置；PULSE 额度每半年重置。只导入部分结单时，剩余额度可能高于实际。
- **登记信息缺失时有默认假设**：赏世界按已登记且 5X 全部分配估算；若结单有明确分配倍数则采用记载。历史回算忽略个人登记生效期，实际资格仍以银行记录为准。
- **退款不赚取奖励，也不扣回此前估算或恢复消费额度**。还款、费用、现金预借及其他排除项目不计奖。
- **卡片收益分别展示**，只有存在明确归属证据时才共享消费额度；关系不明时分开估算并提示。
- **缺少依据会保留提示**：地区、币种和支付方式由结单信息判断，不能手动修改交易或奖励规则。缺少汇率的部分显示“待换算”或“待计算”，不会当作零奖励。
- **计算保留六位 RC**，主金额四舍五入显示两位。各半年或卡片的显示值相加，可能与总览相差 0.01；显示舍入不影响实际累计。

赏世界消费额度优先采用银行给出的港币等值，缺失时使用参考汇率估算。因此参考汇率更新后，人民币参考价值和部分受封顶影响的附加 RC 都可能变化。

## 隐私与联网

| 数据 | 如何处理 |
| --- | --- |
| PDF 与密码 | 仅用于本机读取及解锁，处理完成后释放；不上传、不保存原件或密码 |
| 结单数据与返现结果 | 只保留在当前页面，刷新、关闭或“重新开始”后清空 |
| 公开参考汇率 | 缓存报价、参考日期及获取时间，按香港自然日复用；清空返现结果时保留此缓存 |

真实结单导入后，工具会自动向 [Frankfurter](https://frankfurter.dev/) 获取 ECB 的港币兑人民币参考汇率，跨日自动更新，失败后自动重试。请求不携带结单、密码、卡号、商户或交易金额，工具不使用埋点统计。示例使用虚构汇率。

当前没有账户注册、历史记录、保存或导出功能。请在刷新或关闭页面前查看所需结果；之后需要重新选择结单。

## 遇到问题

| 提示或情况 | 可以怎么做 |
| --- | --- |
| 文件需要密码 | 在“文件状态”中解锁；连续输错 5 次后需等待 60 秒 |
| 未识别结单或没有可读取文本 | 确认是支持卡种的英文文本 PDF，且文件完整；扫描件暂不支持 |
| 部分文件处理失败 | 查看具体失败原因，处理后重新选择这些文件；成功文件会在本批结束后统一计入 |
| 相同文件已跳过 | 该 PDF 已在本批或当前结果中，无需重复加入 |
| 疑似重复或结欠核对有差异 | 对照原结单检查；疑似重复交易和已读交易仍可能计入估算，提示不会自动删除它们 |
| 参考汇率暂不可用 | 等待自动重试；已能确定的奖励仍会显示，依赖汇率的部分暂时待计算 |
| 达到累计文件或大小限制 | 减少本次选择，或确认已查看结果后“重新开始” |
