# Reward+

导入 HSBC PULSE 银联双币钻石卡的英文 PDF 账单，在本机查看预计返现（RewardCash）、逐卡明细和剩余消费额度。

**[打开 Reward+](https://rewards.lmmmmmm.dev/)**

## 开始使用

1. 点击「选择 PDF 文件」，或将一份或多份 PDF 拖入页面。
2. 在「文件状态」中查看进度；加密账单需在页面中输入密码解锁。关闭弹窗后仍会继续处理。
3. 本批处理结束后，成功文件统一计入估算。查看返现总览、逐卡明细，或按每年 1–6 月、7–12 月切换结果。
4. 需要补充账单时，等本批结束后再次选择文件，或在文件状态中点击「补充文件」。

还没有准备好账单时，可在空白页面点击「查看示例」，体验多卡、多币种、消费封顶和退款等场景。导入自己的 PDF 后，示例会被替换；「重新开始」后可再次查看示例。

「取消本批导入」会撤销尚未计入的本批文件，保留此前结果。「重新开始」并确认后，清空当前账单、文件状态和返现结果。

顶部「English / 简体中文」可随时切换语言，不影响结果或正在处理的文件。页面优先沿用手动选择，否则按浏览器语言偏好显示，无匹配时使用简体中文。刷新时直接显示所选语言；语言初始化失败时回退简体中文，不改写已保存的偏好，仍可手动切换。界面语言不改变仅支持英文账单的范围。

## 支持范围

| 项目 | 范围 |
| --- | --- |
| 卡种与格式 | HSBC PULSE 银联双币钻石卡英文文本 PDF，支持本机解锁加密账单 |
| 单份限制 | 不超过 25 MB、200 页 |
| 当前页面累计限制 | 最多 20 份、合计 100 MB，含分批补充 |
| 暂不支持 | 扫描件、图片、其他语言或卡种；不支持扫描文字识别（OCR） |

建议使用 Chromium 浏览器；Safari 和 Firefox 的兼容性尚待验证。交易和规则不可手动修改。

## 怎样理解结果

页面展示基础奖励、赏世界和 PULSE 专属奖励三项预计返现，以及消费金额、计奖或排除原因、消费额度用量和数据质量提示。质量提示随所选半年关联的来源账单变化，账单余额核对始终覆盖完整来源账单；同一账单跨半年时可在两个半年出现，全部周期只计一次。

总览与逐卡结果会列出当前采用的登记、分配倍数、额度关系及参考汇率假设。「查看计算与依据」打开返现明细，可切换计算依据、交易明细和账单核对。计算依据先展示总额和三项奖励，再说明本次假设及规则版本；登记状态和分配倍数分别说明，不覆盖账单已识别的信息。各页补充口径固定在弹窗底部，正文独立滚动。

点击总览提示中的「查看相关记录」、卡片的「查看明细」或具体计奖原因，可定位相关记录；卡片上的额度与质量标签仅展示状态。交易按每页 20 笔展示，并可查看三项奖励与来源账单。来源文本只在本机按需展开，不保留 PDF 原件。账单核对按币种展示期初余额、本期借贷、计算所得期末余额、账单期末余额及差额，差额为后者减前者。补充批次尚未结束时，当前结果只包含此前已提交的账单。

**RC 为预计 RewardCash，实际返现以银行记录为准。** 人民币参考价值按 `1 RC ≈ 1 HKD`，再以参考汇率折算，不代表已发放或可立即兑换的金额。「返现规则与说明」提供奖励条件、费率、消费上限、示例、核实日期及官方来源。

阅读结果时，请留意以下口径：

- **历史账单采用当前已核实规则**，不还原历史活动，也不会自动追踪银行条款变化。
- **消费额度只扣除已导入的消费**，此前占用视为零。赏世界按自然年累计，PULSE 每半年重置；账单不全时，剩余额度可能高于实际。半年结果按交易日期汇总，同一账单可跨多个周期。
- **赏世界登记或倍数信息缺失时**，按已登记、额外 5X 全部分配给赏世界估算；有明确记载时按账单计算。历史估算不受个人登记生效日期限制，实际资格以银行记录为准。
- **退款不赚取奖励，也不扣回此前估算或恢复消费额度**。还款、费用、预借现金等排除项目不计奖。
- **收益逐卡展示**，仅在共享关系明确时合并消费额度；否则分别估算并提示。共享额度的用量不可跨卡重复相加。
- **缺少计算依据的部分保持待计算**，不当作零奖励。已确定的奖励继续展示；地区、币种和支付方式缺少证据时保守判断。
- **RC 计算保留六位小数，页面金额显示两位，计算明细最多显示六位**。非零但舍入为零的奖励显示 `<0.01 RC`。显示舍入不影响计算，各卡或周期显示值相加可能与总览有差异；银行实际返现还可能受未导入的历史消费零头影响。

每个半年及其「额外奖励的消费额度」构成一组，多组结果以留白和分隔线区分。额度区集中展示额度归属、累计截至点、相关来源账单和观测交易范围，同一共享额度池在同一半年内只展示一次。观测日期不代表期间账单完整。

赏世界消费额度优先使用银行港币等值，缺失时按参考汇率估算。汇率更新可能改变人民币参考价值及受消费上限影响的额外奖励。

## 隐私与联网

账单导入与返现计算在本机完成，不向 Reward+ 上传 PDF、密码、账单数据或结果。无账户、历史记录、保存或导出功能，再次查看结果须重新导入。

| 数据 | 处理与保留方式 |
| --- | --- |
| PDF 与密码 | 仅用于本次本机处理，不保存原件或密码，处理完成后释放 |
| 账单数据与返现结果 | 仅保留在当前页面内存，刷新、关闭或「重新开始」后清空 |
| 公开参考汇率 | 仅缓存公开报价、参考日期和获取时间；获取后复用 6 小时，到期自动更新，失败后自动重试 |
| 界面语言 | 手动选择后单独保存在本机；浏览器禁止存储时，仅本页有效 |

导入账单后，工具向 [Frankfurter](https://frankfurter.dev/) 获取 ECB 港币兑人民币公开参考汇率，请求不含账单、密码、卡号、商户或金额，无埋点统计。示例使用虚构汇率，不请求或缓存公开汇率。「重新开始」保留公开汇率缓存和语言偏好。

主动允许 AI 工具读取结果后的共享范围与处理方式见下节。

## 与 AI 工具配合

支持 WebMCP 和文件传入的浏览器 AI 工具，可使用本页已有的分析流程。打开底部「AI 接入」，点击「允许读取结果」后，AI 工具可查询导入进度、预计返现、消费额度、逐笔金额与原因及质量提示，也可通过浏览器传入你指定的 PDF。密码仍在页面中输入。

按钮不可用时，可悬停、键盘聚焦或轻点按钮区域查看原因。未检测到 WebMCP 时，提示会说明在 Chrome 的 `chrome://flags` 中搜索并启用 WebMCP，重启后重试；浏览器支持情况以 [Chrome 官方说明](https://developer.chrome.com/docs/ai/webmcp#local-webmcp)为准。准备中可稍候，接入失败可点击「重试接入」。

共享覆盖当前及本页后续补充导入的结果，交易描述默认不返回。可随时「停止共享」；刷新、关闭或「重新开始」后失效。示例使用虚构数据，可直接读取，切换到真实账单后需开启共享。浏览器或 AI 工具不支持时，仍可正常使用页面导入。

AI 工具可能将读取的结果发送到其模型服务，数据处理方式由工具提供方决定。共享控制只限制本站工具输出，不能认证 AI 工具身份，也不能阻止已具有页面访问权限的扩展读取页面；停止共享不能收回此前已读取的数据。

## 常见问题

| 情况 | 处理方式 |
| --- | --- |
| 文件需要密码 | 在「文件状态」中解锁，或移除该文件；连续输错 5 次后等待 60 秒。仍有待解锁文件时，本批不会计入结果 |
| 未识别账单或无可读取文本 | 检查卡种、英文文本格式及文件完整性；不支持扫描件 |
| 部分文件失败 | 查看原因并重新选择失败文件；成功文件仍会在本批结束后统一计入 |
| 相同文件已跳过 | PDF 已在本批或当前结果中，无需重复加入 |
| 疑似重复或账单余额核对有差异 | 对照原账单检查；提示不会自动删除交易，疑似重复仍可能计入估算 |
| 参考汇率暂不可用 | 等待自动重试；已确定的奖励继续显示，其余待计算 |
| 弹窗内容无法加载 | 点击「重新加载内容」，或关闭后再打开；无需刷新页面 |
| 达到累计文件或大小限制 | 减少本次选择，或查看结果后「重新开始」；重新开始会清空当前结果 |
